This project is a single-page website made with HTML and CSS.
It has two different designs using the same HTML file. 
Changing the CSS file changes the design of the page.
The main challenge was placing the boxes correctly in both designs.
In Style A, I used Flexbox to keep the boxes equally spaced.
In Style B, I had to keep the first five boxes on the same line and the last box in the bottom right corner.
